## 📌 規格書維護守則 (Maintenance Policy)
1. **完成即回寫**：任何新功能開發完成驗收後，必須將最終行為與資料規格回寫至此目錄下對應章節。
2. **單一事實來源 (SSOT)**：本目錄為系統當前實際行為之唯一正式規範。
3. **版本與變更記錄**：重大邏輯變更須在各章節末尾標註變更日期與摘要。
