# 第 3 章：甘特圖時程管理規格 (Gantt Chart)

## 1. 核心模型
* **工作包類型 (Work Package Type)**：
  - `PHASE` (專案階段，如：概念設計、建照送審、發包施工)
  - `TASK` (一般作業任務)
  - `MILESTONE` (關鍵里程碑，例如都審通過、建照取得、上樑)
* **階層關聯 (Hierarchy)**：支援 `parentId` 定義父子樹狀階層。
* **前置依賴 (Dependencies)**：支援 `dependencies: string[]` 定義前置工作包代碼，建立工期連動。

## 2. 視圖操作規格
* 支援時間軸視角切換（日/週/月）。
* 支援進度百分比（0% - 100%）視覺化進度條顯示。
