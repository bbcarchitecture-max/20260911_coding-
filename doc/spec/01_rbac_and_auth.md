# 第 1 章：角色與權限控制規範 (RBAC)

## 1. 角色定義 (Roles)
系統劃分 4 種主要角色：
* **`SUPER_ADMIN` (最高管理員)**：具備全系統所有專案與成員配置之完全控制權。
* **`PM` (專案經理 / 主持建築師)**：管理所屬專案之看板、甘特圖時程、成員指派及審批 RFI。
* **`MEMBER` (團隊成員 / 工程師 / 繪圖員)**：編輯個人承辦之任務、發起 RFI、發表評論與上傳附件。
* **`GUEST_AUDITOR` (訪客稽核員 / 業主代表)**：唯讀檢視看板與進度甘特圖，無法進行修改與刪除。

## 2. 角色切換機制
* 導覽列（Navbar）提供即時角色切換模擬器，方便管理者切換檢驗不同權限視角下的 UI 行為。
