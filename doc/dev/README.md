# 功能開發計畫目錄 (Development Plans)

本目錄存放所有新功能開發前的**討論與實作計畫**。

---

## 📌 開發工作流程原則 (Strict Workflow Policy)

1. **先討論後寫計畫**：在動工寫程式前，必須先與使用者討論確認需求，並在此目錄撰寫實作計畫。
2. **命名規範**：計畫檔案必須使用 `plan_<功能名稱>.md` 格式命名（例如：`plan_drawing_versioning.md`、`plan_export_pdf.md`）。
3. **參照執行**：實作過程中以該計畫為藍圖逐步執行與驗收。
4. **回寫規格**：功能開發驗收完成後，**必須將最終規格分章節寫回 `doc/spec/`**。
5. **歸檔標記**：開發完成之計畫可在文件頂端標註 `[STATUS: COMPLETED]` 與完成日期。

---
